usage: novel.py [-h]
                {init,status,draft,count,check,query,settle,retcon,export,rebuild} ...

WorkBuddy 长篇网文书仓确定性工具（仅标准库）

positional arguments:
  {init,status,draft,count,check,query,settle,retcon,export,rebuild}
    init                从模板生成书仓
    status              从文件推导进度
    draft               创建章节草稿骨架
    count               统计汉字数
    check               确定性检查
    query               全文检索
    settle              作者确认后定稿入档
    retcon              设定修订留痕
    export              导出定稿合集
    rebuild             从文件重建 state.json

options:
  -h, --help            show this help message and exit

usage: novel.py init [-h] --root ROOT [--json] --title TITLE [--genre GENRE]
                     [--platform PLATFORM] [--pov POV] [--min MIN]
                     [--target TARGET] [--max MAX] [--force]

options:
  -h, --help           show this help message and exit
  --root ROOT          书仓根目录
  --json               输出机器可读 JSON（部分命令支持）
  --title TITLE        书名
  --genre GENRE        题材
  --platform PLATFORM  目标平台
  --pov POV            叙事人称
  --min MIN            下限汉字数
  --target TARGET      目标汉字数
  --max MAX            上限汉字数
  --force              允许覆盖 config.json（不删除已有文件）
